# مونتاژ مقاله در LaTeX

این پوشه، نسخه‌ی قابل‌کامپایل مقاله است که متن موجود
(`../first artcel text.txt`) را با بخش‌های نوِ پیش‌نویس (`../draft/*.md`)
مطابق نگاشت `../evidence/integration_plan.md` ادغام می‌کند.

## پیش‌نمایش HTML و نسخه‌ی قابل‌ارسال برای بازبینی

برای خواندن متن بدون کامپایل LaTeX:

```
python ..\tools\tex2html.py     # → manuscript/preview.html
```

خروجی خودبسنده است: قلم وزیرمتن به‌شکل `data:` داخل خودِ HTML جاسازی
می‌شود (چون کروم در `file://` بارگیری قلم از کنار فایل را با خطای CORS
رد می‌کند)، پس با دوبار کلیک هم درست دیده می‌شود؛ فقط شکل‌ها و MathJax
از کنار فایل خوانده می‌شوند و برای همین ارسال، زیپِ زیر را بسازید.

و برای ساختن یک زیپِ خودبسنده که به دست داور/همکار می‌دهید:

```
python ..\tools\vendor_mathjax.py   # یک‌بار، MathJax را محلی می‌کند
python ..\tools\make_review_zip.py  # → maghale-preview.zip در ریشه‌ی مخزن
```

گیرنده زیپ را باز می‌کند و روی `index.html` دوبار کلیک می‌کند. بسته
کاملاً آفلاین است: قلم، MathJax و شکل‌ها همه داخل آن‌اند. حجم کل حدود
۹۴۵ کیلوبایت است. در آن نسخه هر پاراگراف یک شماره‌ی حاشیه‌ای دارد تا
داور بتواند بنویسد «پاراگراف ۱۴، جمله‌ی دوم».

## کامپایل

> **وضعیت فعلی:** روی این سیستم هیچ توزیع LaTeX نصب نیست و **مسیر داکر
> به دستور کاربر رها شده است**؛ `docker/Dockerfile` هرگز آزموده نشده.
> پس تا اطلاع ثانوی **PDF ساخته نمی‌شود** و تحویل رسمی همان بسته‌ی
> HTML بالا است. دستورهای زیر برای زمانی است که یک موتور TeX در دسترس
> باشد.

اگر توزیع LaTeX روی سیستم دارید:

```
latexmk -xelatex main.tex
```

یا به‌صورت دستی:

```
xelatex main
biber   main
xelatex main
xelatex main
```

**موتور باید XeLaTeX باشد** — نه pdfLaTeX. بسته‌ی `xepersian` به
XeTeX نیاز دارد.

<details>
<summary>مسیر داکر (آزموده‌نشده — بدون تأیید کاربر اجرا نکنید)</summary>

```
powershell -File ..\docker\build.ps1
```

خروجی موردانتظار: `manuscript/main.pdf` و لاگ در `manuscript/build.log`.
چون رجیستری، تصویرهای آماده‌ی TeX Live را نمی‌داد، `docker/Dockerfile`
تِک‌لایو را از apk روی `alpine:3.20` نصب می‌کند؛ این مسیر هیچ‌گاه تا انتها
اجرا نشده و ممکن است بسته‌های لازم `xepersian` را کامل نداشته باشد.

</details>

### قلم

قلم متن **وزیرمتن** است و فایل‌های `.ttf` آن در `fonts/` همین پوشه قرار
دارد، پس نیازی به نصب قلم روی سیستم نیست: `main.tex` نخست همان مسیر را
امتحان می‌کند و اگر نبود سراغ نسخه‌ی نصب‌شده‌ی `Vazirmatn`، سپس
`XB Niloofar` و سپس `Noto Naskh Arabic` می‌رود. پروانه‌ی قلم در
`fonts/OFL.txt` است. (این مسیر تنها روی ویندوز آزموده شده؛ کامپایل در
داکر انجام نشده است.)

### اگر `biber` در دسترس نبود

`biblatex` را با گزینه‌ی `backend=bibtex` بارگذاری کنید، یا فهرست مراجع
را با `\bibliographystyle{unsrt}` و `\bibliography{references}` جایگزین
کنید. کلیدهای ارجاع در هر دو حالت یکسان‌اند.

## دو نکته‌ی مهم

1. **شکل‌ها درج شده‌اند.** سه شکل خروجی Lumerical در `figures/` هستند و
   هر سه سطر `\includegraphics` در `sections/04_results.tex` فعال است:
   `Test2_Purcell.pdf`، `Test2_Radiated.pdf`، `Test2_Nearfield_controls.pdf`.
   دو نمودار برداری‌اند (خروجی GL2PS داخل VTK) و XeLaTeX همان PDF را درج
   می‌کند. برای پیش‌نمایش HTML، `tools/figures_prep.py` نسخه‌ی PNG آن‌ها
   را در `figures/web/` می‌سازد. اگر شکل نویی افزودید:

   ```
   python ..\tools\figures_prep.py    # PNG وب را بساز
   python ..\tools\tex2html.py        # پیش‌نمایش را به‌روز کن
   ```

   سوئیچ `--clean` جریان محتوای PDF را هم بازنویسی می‌کند؛ خروجی
   GL2PS 1.3.8 عملگر شفافیت `ca` را داخل جریان محتوا می‌نویسد که خلاف
   مشخصات PDF است. بازنویسی، نسخه‌ی دست‌نخورده را با پسوند `.orig.pdf`
   نگه می‌دارد و تنها وقتی می‌پذیرد که تصویر پیش و پس از آن پیکسل‌به‌پیکسل
   یکسان بماند.
2. **پارامترهای هندسی درج شده‌اند.** بخش روش‌شناسی اکنون اعداد اجرای
   گزارش‌شده را دارد: $L = 60$ نانومتر (بدنه‌ی ۴۰ + دو کلاهک ۱۰)،
   $D = 20$، $R = 10$، دوقطبی در $z = 35$ نانومتر، مش موضعی ۲ نانومتر با پوشش پویای ساختار و چشمه، شش مانیتور وجهی روی
   مکعب شار ۴۰۰ نانومتری و ناحیه‌ی
   FDTD مکعب ۶۰۰ نانومتری با PML. همین مقادیر در
   `simulation/nanorod_purcell.lsf` هم همگام شد. ثبت راستی‌آزمایی با
   شماره‌ی سطر منبع: `../evidence/source_audit.md`.

## راستی‌آزمایی

```
python ../evidence/check_manuscript.py     # ساختار .tex و انطباق ارجاع‌ها
python ../evidence/check_refs.py           # پیش‌نویس‌های .md با .bib
python ../tools/check_preview.py           # سلامت preview.html
```

خروجی‌ها در `../evidence/_mscheck.txt` و `../evidence/_refcheck.txt`
نوشته می‌شوند. آخرین اجرا: بدون خطا — ۲۷ مدخل کتاب‌نامه، ۲۷ کلید
ارجاع‌شده، هیچ کلید تعریف‌نشده، هیچ مدخل بی‌استفاده، هیچ `\ref` بی‌هدف.
`check_preview.py` هم چهار چیز را می‌سنجد و آخرین اجرایش سالم بود:
لنگر بی‌هدف ندارد (از جمله `eq:loss`)، قلم به‌شکل `data:` جاسازی شده،
MathJax محلی است، و هیچ دستور لاتک ترجمه‌نشده‌ای بیرون از ریاضی نمانده.
