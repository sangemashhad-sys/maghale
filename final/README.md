# نسخه‌ی نهایی مقاله (درس پروژه)

- `maghale_final.html` — فایل نهایی و خودبسنده (قلم، فرمول‌ها و شکل‌ها داخل خود فایل). در کروم باز کنید و با Ctrl+P → «Save as PDF» (کاغذ A4، حاشیه‌ی پیش‌فرض) خروجی بگیرید.
- `maghale_final_preview.pdf` — همان خروجی، چاپ‌شده با Chromium برای پیش‌نمایش (۲۲ صفحه).
- `src/` — منبع: `article.html` (متن)، `refs.js` (مراجع)، `style.css`، `fig/`، `build.js`.

ساخت دوباره پس از ویرایش متن:

```
cd final/src
npm install mathjax-full@3      # یک‌بار
node build.js
```

ارجاع در متن با `{{کلید}}` یا `{{کلید|pp. 34–37}}` نوشته می‌شود؛ شماره‌گذاری به ترتیب ظهور خودکار است.

## صفحه‌آرایی چاپی

- هر بخش اصلی (مقدمه، مبانی نظری، روش، نتایج، نتیجه‌گیری، پیوست، مراجع) در چاپ از بالای صفحه‌ی تازه شروع می‌شود.
- چند زیربخش با کلاس `pb` (مثلاً `<h3 class="pb">`) عمداً به صفحه‌ی بعد رفته‌اند تا تیتر ته صفحه نماند. اگر متن را تغییر دادید، خروجی را دوباره نگاه کنید و در صورت لزوم این کلاس را اضافه یا حذف کنید.
- شکل‌ها به ترتیب نخستین ارجاع در متن شماره‌گذاری شده‌اند.
