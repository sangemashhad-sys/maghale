# یادداشت‌های پایدار پروژه مقاله

این پوشه برای انتقال کامل وضعیت پروژه میان انسان‌ها یا عامل‌های هوش مصنوعی ساخته شده است. اطلاعات این پوشه باید همراه با هر تغییر مهم مقاله به‌روز شود.

## وضعیت فعلی

- مرحله جاری: **شناخت عمیق مقاله و بازسازی تاریخچه آن**
- در این مرحله متن علمی مقاله تغییر داده نشده است.
- مقاله هدف یک دانشجوی ترم ۷ کارشناسی فیزیک دانشگاه اصفهان است.
- قالب نهایی دانشگاه/استاد بعداً ارائه خواهد شد.
- نسخه اصلی قابل بررسی: `manuscript/main.tex`
- متن پایه پیش از افزودن لایه نظری جدید: `first artcel text.txt`
- تاریخچه گفت‌وگوی شکل‌گیری پروژه: `chat about articel.txt`

## اسناد این پوشه

1. [`01_article_identity.md`](01_article_identity.md): ماهیت، هدف، پرسش و معماری مقاله
2. [`02_history_and_lineage.md`](02_history_and_lineage.md): تاریخچه شکل‌گیری و منشأ هر لایه
3. [`03_repository_map.md`](03_repository_map.md): نقش فایل‌ها و میزان اتکاپذیری آن‌ها
4. [`04_open_questions.md`](04_open_questions.md): ابهام‌هایی که باید پیش از اصلاح مقاله حل شوند
5. [`CURRENT_STATE.md`](CURRENT_STATE.md): نقطه دقیق توقف و دستور ادامه کار

## قاعده ادامه کار

پیش از هر اصلاح علمی یا LaTeX، ابتدا اسناد ۱ تا ۵ خوانده شوند. هیچ عامل بعدی نباید نسخه فعلی را یک متن یک‌پارچه با منشأ واحد فرض کند؛ این نسخه از یک مقاله عددی پایه و یک لایه نظری/نقدی متأخر تشکیل شده است.
