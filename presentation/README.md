# پوشه‌ی ارائه

| فایل | چیست |
| --- | --- |
| `slides.html` | **اسلایدهای ارائه** — خروجی ساخته‌شده؛ در مرورگر باز کنید (کلیدهای ←/→ یا Space برای جابجایی، N برای دیدن یادداشت‌های سخنران). کاملاً آفلاین: قلم وزیرمتن به‌صورت `data:` جاسازی شده و MathJax از `../manuscript/vendor/mathjax/` می‌آید. |
| `slides_template.html` | منبع اسلایدها. **این را ویرایش کنید**، نه `slides.html` را. |
| `build_slides.py` | منبع → خروجی: قلم‌ها را جاسازی و نشانی MathJax را می‌گذارد. پس از هر ویرایش قالب اجرا کنید: `python build_slides.py` |
| `راهنمای_ارائه_کلاسی.md` | نقشه‌ی راه ارائه: ترتیب اسلایدها با زمان‌بندی، جدول اعداد کلیدی، و سؤال‌وپاسخ‌های محتمل استاد با پاسخ آماده. |

## اجرا

- از طریق سرور محلی: `http://localhost:8001/presentation/slides.html`
  (سرور باید از ریشه‌ی مخزن سرو بدهد، چون اسلایدها شکل‌ها و MathJax را با
  نشانی نسبی `../manuscript/...` می‌خوانند.)
- یا بدون سرور: روی `slides.html` دوبار کلیک کنید. قلم و فرمول‌ها درست
  دیده می‌شوند؛ فقط شکل‌ها و MathJax باید کنار همین پوشه بمانند (ساختار
  مخزن را جابه‌جا نکنید).

## چاپ / PDF

در مرورگر Ctrl+P بگیرید: هر اسلاید یک صفحه می‌شود و یادداشت‌های سخنران در
چاپ نمی‌آیند.

## تغییر نام‌ها

نام دانشجویان و استاد در دو جا هست: `manuscript/main.tex` (بلوک
`\author`) و `slides_template.html` (اسلاید ۱). هر دو را عوض کنید و بعد
`python build_slides.py` و `python ../tools/tex2html.py` را اجرا کنید.
