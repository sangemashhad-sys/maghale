اجرای سوم شبیه‌سازی — فقط ۳ قدم (حدود ۵ دقیقه)
================================================

هیچ کدی لازم نیست بفهمی یا عوض کنی. فقط:

قدم ۱)  Lumerical FDTD را باز کن.
        File → New → File   و بعد   File → Save As
        و آن را در یک پوشه‌ی خالی ذخیره کن، مثلاً:   D:\nanorod3\work.fsp
        (مهم: پوشه‌ی جدید و خالی باشد، نه همان پوشه‌ی دفعه‌ی قبل)

قدم ۲)  از منوی بالا:  Script → Script File Editor  (یا کلید F5)
        در پنجره‌ی باز شده:  File → Open  و فایل کنار همین متن را انتخاب کن:
            NANOROD_RUN_CASES_round3.lsf
        بعد دکمه‌ی Run (فلش سبز) را بزن.

قدم ۳)  صبر کن تا در پنجره‌ی Script Prompt این خط بیاید:
            ##########  ALL CASES DONE  ##########
        (۷ حالت اجرا می‌شود، هر کدام حدود ۳۰ ثانیه تا ۱ دقیقه.)
        بعد برو داخل پوشه‌ی D:\nanorod3 و همه‌ی فایل‌هایی که پسوند .txt و .log
        دارند را انتخاب کن → راست‌کلیک → Send to → Compressed (zipped) folder
        و آن زیپ را بفرست. (فایل‌های .fsp حجیم‌اند، لازم نیست بفرستی.)

اگر وسط کار قطع شد یا خطا داد:
   دوباره Run بزن. حالت‌هایی که تمام شده‌اند خودکار رد می‌شوند.

اگر پیام "license" یا "engine" داد:
   یعنی Lumerical در حالت اجرای شبیه‌سازی نیست؛ همان کاری را بکن که دفعه‌ی قبل
   برای اجرای B و C و D کردی.
