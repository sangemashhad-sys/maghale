# راهنمای اجرای شبیه‌سازی BEM (MNPBEM) روی لپ‌تاپ

این شبیه‌سازی عدد دقیق فاکتور پرسل را برای مقاله‌ی ISI می‌دهد. Meep در شکاف ۵ نانومتری به عدد همگرا نرسید، اما روش BEM سطح ذره را دقیق مدل می‌کند و این مشکل را ندارد.
کل کار سه مرحله دارد: **نصب (۱۰ دقیقه)**، **اجرای آزمایشی (۵ تا ۲۰ دقیقه)** و **اجرای اصلی (چند ساعت، بدون نیاز به حضور)**.

---

## ۱. سخت‌افزار و نرم‌افزار لازم

| | حداقل | پیشنهادی | توضیح |
|---|---|---|---|

## ۲. نصب (فقط یک بار)

1. **دانلود MNPBEM17** (رایگان، مجوز GPL): به <https://github.com/Nikolaos-Matthaiakakis/MNPBEM> بروید،
   دکمه‌ی سبز **Code** و بعد **Download ZIP** را بزنید و پوشه‌ی داخل zip را `MNPBEM17` نام‌گذاری کنید.
2. یک پوشه بسازید، مثلاً `C:\bem`، و این دو چیز را داخلش بگذارید:
   - فایل **`run_mnpbem.m`** (از همین پوشه‌ی گیت‌هاب، یا با فلش)
   - محتوای `mnpbem17.zip` را همین‌جا Extract کنید تا پوشه‌ای به نام **`MNPBEM17`** ساخته شود

   ساختار نهایی باید این باشد:
   ```
   C:\bem\
     run_mnpbem.m
     MNPBEM17\        ← داخلش پوشه‌هایی مثل Particles, BEM, Material, ... هست
   ```
   اگر نام پوشه چیز دیگری شد، مثلاً `MNPBEM17\MNPBEM17`، مشکلی نیست. فقط مسیر کامل آن را در خط
   `MNPBEM_DIR = '...'` بالای اسکریپت بنویسید.
3. لینک مستقیم دانلود اسکریپت:
   <https://raw.githubusercontent.com/aminsadidi/maghale/claude/sleepy-rubin-e80q4k/isi/bem/run_mnpbem.m>
   (روی صفحه راست‌کلیک کنید و Save as بزنید. پسوند فایل باید `.m` باشد، نه `.m.txt`.)

## ۳. اجرای آزمایشی (حتماً اول این)

1. MATLAB را باز کنید. در نوار Current Folder بالای صفحه به پوشه‌ی `C:\bem` بروید.
2. فایل `run_mnpbem.m` را باز کنید. خطی که با `MODE` شروع می‌شود (نزدیک خط ۱۵) باید این باشد: `MODE = 'test';`
3. دکمه‌ی سبز **Run** را بزنید. اگر پیغام «Change Folder / Add to Path» آمد، **Change Folder** را بزنید.
4. در Command Window خط‌هایی مثل این می‌آید:
   ```
   --- test_rod_L60_h3_air: 560 boundary elements, apex at z = 30.000 nm, ...
       test_rod_L60_h3_air  lambda= 500.0 nm  Fp_z(5 nm)= ...  | 4.2 s/lambda, 1/9, case done in ~34 s
   ```
5. در آخر جدولی با عنوان **`estimated run time of MODE = 'full'`** چاپ می‌شود که زمان تخمینی هر حالت و جمع کل (`TOTAL`) را می‌دهد.
6. **از این جدول یک عکس بگیرید و برای من بفرستید.** فایل `results_bem_test.zip` هم کنار اسکریپت ساخته می‌شود. اگر بشود آن را هم بفرستید.

اگر خطای قرمز آمد، فایل `results_bem\log_test.txt` را بفرستید. اسکریپت را درست می‌کنم و نسخه‌ی جدید می‌دهم.
(جزئیات API نسخه‌های مختلف MNPBEM کمی فرق دارد. اجرای آزمایشی برای همین است که اگر جایی ناسازگار بود، قبل از اجرای چندساعته معلوم شود.)

## ۴. اجرای اصلی

1. در همان خط `MODE` بنویسید: `MODE = 'full';` و فایل را ذخیره کنید (Ctrl+S).
2. **قبل از Run:**
   - شارژر لپ‌تاپ وصل باشد.
   - **Sleep خاموش باشد.** در ویندوز: Settings → System → Power → Screen and sleep: هر دو را **Never** بگذارید. اگر لپ‌تاپ بخوابد، اجرا متوقف می‌شود.
   - برنامه‌های سنگین دیگر بسته باشند.
3. **Run** را بزنید و لپ‌تاپ را به حال خودش بگذارید. پیشرفت و زمان باقی‌مانده‌ی هر حالت مرتب چاپ می‌شود.
4. در پایان پیغام `=== finished ... Send this file back: ...\results_bem_full.zip ===` می‌آید.
   **فایل `results_bem_full.zip` را بفرستید.** فقط همین یک فایل کافی است.

### اگر وسط کار قطع شد
مشکلی نیست. **دوباره Run بزنید.** طول‌موج‌هایی که حساب شده‌اند نگه داشته می‌شوند و اجرا از همان‌جا ادامه پیدا می‌کند.
می‌شود عمداً هم وسط کار با **Ctrl+C** در Command Window متوقف کرد، مثلاً شب اجرا کرد، صبح قطع کرد و شب بعد ادامه داد.

### اگر کار تمام نشد ولی وقت نداریم
همان `results_bem` را zip کنید و بفرستید. حالت‌ها به ترتیب اهمیت مرتب شده‌اند و اول مهم‌ترها اجرا می‌شوند:
1. کره در برابر تئوری دقیق Mie (اعتبارسنجی)
2. نانومیله با مش‌های ۲، ۱٫۵ و ۳ نانومتر (نتیجه‌ی اصلی مقاله)
3. مش‌های ریزتر (همگرایی)
4. نسبت ابعاد مختلف و محیط آب

## ۵. اشکالات رایج

| پیغام | راه‌حل |
|---|---|
| `MNPBEM17 not found` | پوشه‌ی `MNPBEM17` کنار اسکریپت نیست. مسیرش را در `MNPBEM_DIR` بنویسید. |
| `gold.dat ... not found` | پوشه‌ی کامل MNPBEM17 Extract نشده است. دوباره از zip باز کنید. |
| `skipped: needs ~X GB` | رم کافی برای آن حالت نیست. خودکار رد می‌شود و بقیه اجرا می‌شوند. |
| `Out of memory` | MATLAB و برنامه‌های دیگر را ببندید و دوباره Run بزنید (ادامه می‌دهد). |
| `!!! case ... failed` | آن حالت رد شده و بقیه ادامه دارند. در پایان فایل log را هم بفرستید. |

## ۶. برای خود ما (جزئیات فنی)

- **حل‌گر:** MNPBEM17، BEM کامل و تأخیری (`'sim','ret'`) با درون‌یابی سطح منحنی (`'interp','curv'`)، طلا با داده‌ی Johnson–Christy (`gold.dat`).
- **خروجی‌ها:** برای هر حالت یک CSV با ستون‌های `lambda_nm` و سپس برای هر شکاف g: `Fp_z_g, T_z_g, Fp_x_g, T_x_g`.
  - `Fp` = نرخ واپاشی کل و `T` = نرخ تابشی، هر دو نسبت به همان دوقطبی در محیط میزبان همگن.
  - `z` = دوقطبی محوری و `x` = دوقطبی عرضی، هر دو روی محور تقارن.
  - همه‌ی شکاف‌ها (۳، ۵، ۷، ۱۰، ۱۵، ۲۰ nm) در یک حل محاسبه می‌شوند.
- **حالت‌ها:**
  - کره‌ی هم‌حجم با ۴۰۰، ۷۸۴ و ۱۴۴۴ رأس
  - میله‌ی L=60 با اندازه‌ی المان ۳، ۲، ۱٫۵ و ۱ nm
  - L = 40، 50، 80 و 100
  - آب (n=1.33) برای میله و کره
- **بررسی خودکار هندسه:** اسکریپت طول واقعی میله را از رأس‌های مش می‌خواند. اگر قرارداد `trirod` (طول با کلاهک یا بدون آن) متفاوت باشد، آن را اصلاح می‌کند. دوقطبی دقیقاً `gap` نانومتر بالای نوک قرار می‌گیرد.
- **تحلیل بعد از برگشت فایل:**
  ```
  python isi/analysis/ingest_bem.py results_bem_full.zip
  ```
  این دستور کره را با Mie دقیق مقایسه می‌کند. هر دو جهت شعاعی و مماسی در `isi/sim/mie.py` هستند و Mie هم از همان داده‌ی جدولی JC استفاده می‌کند. بعد همگرایی مش، نسبت‌های جهتی و میانگین جهتی را درمی‌آورد و خروجی را در `isi/results/bem/summary.md` و `isi/figures/fig_bem_convergence.pdf` می‌نویسد.
- **وضعیت آزمون:**
  - منطق اسکریپت (ادامه بعد از قطعی، اصلاح طول میله، نوشتن CSV، تخمین زمان و ادامه بعد از خطای یک حالت) در Octave با نسخه‌ی شبیه‌سازی‌شده‌ی توابع MNPBEM آزموده شد.
  - خود MNPBEM اینجا اجرا نشد، چون دانلودش ثبت‌نام می‌خواهد و MATLAB در دسترس نیست. اجرای آزمایشی برای همین است.
- **مرجع:** U. Hohenester & A. Trügler, Comput. Phys. Commun. **183**, 370 (2012), [arXiv:1109.5783](https://arxiv.org/abs/1109.5783).
